## 修复 electron-dev 下的 Chromium 缓存噪声日志
- 现象：`npm run electron-dev` 控制台刷 `net/disk_cache: Unable to move the cache: 拒绝访问 (0x5)` 与 `Gpu Cache Creation failed: -2`，应用本身正常（Client connected、系统分配端口均工作）。
- 根因：dev 模式 Chromium 把 HTTP 磁盘缓存 + GPU 缓存建在 `userData` 下，会先在临时位置创建再 move 到目标目录，Windows 上该 move 偶发 0x5；属无害噪声。`data.json` 仍能正常写入 `userData`，说明 userData 本身可写。
- 修复（`electron-main.js`，仅 `!app.isPackaged` 生效）：
  - 顶部先 `const REAL_USER_DATA = app.getPath('userData')` 固定真实路径。
  - dev 下 `fs.mkdirSync` 在 `app.getPath('temp')/envswitch-dev-cache` 建目录，并 `app.setPath('userData', devCacheDir)` 把 Chromium 缓存（HTTP+GPU）重定向到临时目录。
  - `getAppDataPath()` 改为返回 `REAL_USER_DATA`，保证 `data.json` 仍落在原始 userData（dev 数据不丢）。
  - 打包后不受影响，沿用默认 userData。
- 验证：`node --check electron-main.js` 通过；全文件仅 line 13 一处 `app.getPath('userData')` 用于捕获真实路径。无法在此沙箱实测 GUI，但为标准做法；用户本地重跑 `npm run electron-dev` 即可确认噪声消失。
